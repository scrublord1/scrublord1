YT Psych Uploader

YT Psych Uploader is a personal automation tool used by a single YouTube creator to publish original educational videos about human psychology and behaviour to their own channel, read comments on those videos, and review the channel's own analytics. It uses YouTube API Services.

It is not offered to the public and does not access any account other than the creator's own.
